# Pokedex Flutter

The Pokedex Flutter app is a mobile application that displays a list of Pokémon along with their details. Built using the Flutter framework, this app leverages the public API from PokeAPI. It is designed to help users explore the world of Pokémon, view stat, evolutions, and other information.

## Key Features
- **Pokémon List**: Displays a list of Pokémon with pagination.
- **Pokémon Details**: Shows detailed information about Pokémon, including stats, types, evolutions, and moves.
- **Search**: Search for Pokémon by name or number. (Coming Soon)
- **Responsive Design**: Responsive layout for various screen sizes (portrait and landscape).
- **Battle Simulation**: Simple battle simulation between the player's Pokémon and an enemy. (tap pokemon image in detail screen -> start battle)

## Technologies Used
- **PokeAPI**: Public API for fetching Pokémon data. [Poke API](https://pokeapi.co/)
- **AudioPlayers**: For playing Pokémon cry sounds.
- **Flutter SVG**: For rendering SVG images (e.g., Pokeball).
- **Riverpod**: State management for managing app state.
- **Dio**: For making HTTP requests to the PokeAPI.
- **Sliding Up Panel**: For the sliding panel UI in the Pokémon detail screen.
- **Shimmer**: For displaying shimmer effects during loading.
